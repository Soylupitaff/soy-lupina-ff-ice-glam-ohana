# SOY LUPITA FF — Princess Ice OHANA

Página personal de Soy Lupita FF con estética rosa pastel y azul hielo.

## Archivos
- `index.html`: contenido de la página.
- `style.css`: diseño adaptable a celular y computadora.
- `script.js`: menú móvil y año del pie de página.
- `assets/`: imágenes de la presentación, EmoteLab, Stitch y Rango Creador.

## Publicar en GitHub Pages
En Settings → Pages, selecciona `Deploy from a branch`, branch `main` y carpeta `/(root)`.
